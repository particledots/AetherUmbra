AetherUmbra third-party components

1. Oneiroi firmware (third_party/oneiroi-firmware)
   Befaco, https://github.com/Befaco/Oneiroi, written by Roberto Noris (hirnlego) with contributors, GNU GPL version 3
   (see third_party/oneiroi-firmware/LICENSE; LICENSE_VCV.md in the same folder is a dual-licensing note by the
   contributors, it does not change the GPL-3.0-or-later terms for this use; it will be read again in full before anything
   is shared). Imported at the commit named in third_party/oneiroi-firmware/SOURCE.txt, byte for byte, which the build
   checks file by file. As of Milestone 1 the engine files are compiled into the plugin. Two small changes (Filter.h, DelayLine.h) are marked
   "AetherUmbra change" and listed in third_party/oneiroi-firmware/AETHERUMBRA-CHANGES.md.
   AetherUmbra is an unofficial port. It is not made, approved or supported by Befaco. The Befaco panel design and
   artwork are not used.
   The Oneiroi source says that parts are ported or adapted from Mutable Instruments code by Emilie Gillet (comments in
   Commons.h "taken from pichenettes' stmlib" and "adapted from code found in the eurorack repo", Limiter.h "from
   Rings", ParamController.h "from Plaits"); that code is covered in 1b. Two files, ChaosNoise.h and TGate.h, are ports
   from pbat.ch sndkit, and StereoSuperSaw.h is adapted from a published thesis (Adam Szabo, KTH, 2010): the licences
   of those two sources have NOT been checked yet and are to be checked in Milestone 2, before anything is shared.
